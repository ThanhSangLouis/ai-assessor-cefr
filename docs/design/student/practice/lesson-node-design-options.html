6 bộ node bài học · so sánh sáng / tối

Chọn kiểu node sách. Node cúp cuối giữ nguyên thiết kế và màu trạng thái hiện tại.

Cúp bên dưới từng bộ là mẫu đối chiếu cố định: bạc khi khóa, cam khi mở, xanh khi hoàn thành. Các phương án A–F chỉ thay node bài học.

Rê chuột, nhấn giữ hoặc dùng Tab để xem hover, pressed và focus. Bấm node chỉ xem trạng thái, không mở hay ghi tiến độ bài học.

Chưa chọn bộ node. Đây là trang thử độc lập, chưa thay đổi /practice.
