# Khu quản trị

Trang `/admin` (Tài khoản, Mô hình, Cấu hình, Đơn hàng, Dữ liệu, AI viết lại, Vận hành) dùng chung thế giới "Thời khoá biểu khoa" với khu giảng viên: thanh bên mực xanh, tờ kẻ ô trắng, chip band theo màu band, cam chỉ cho việc chính. Xem [../teacher/README.md](../teacher/README.md).

Riêng cho quản trị:

- Thao tác phá huỷ (Tắt tài khoản, Xoá dữ liệu) chỉ có viền đỏ, đứng tách khỏi các nút khác trong hàng, chỉ tô đỏ khi rê chuột hoặc chọn bằng bàn phím.
- Mỗi hàng chỉ có nút phụ (Kích hoạt mô hình, Mật khẩu tạm); nút cam dành cho việc chính của tab (Tạo tài khoản, Lưu ngưỡng mới).
- Bảng số liệu kẻ như thời khoá biểu: đầu bảng nền lõm, đường kẻ mảnh giữa hàng và giữa cột.

Ảnh bản build thật: `evidence/`.
