# TC2.7 — Thực nghiệm người dùng

**Nguồn tiêu chí:** rubric PDF tại docs/rubric/. Trạng thái của folder: PENDING

## Hồ sơ cần có

Protocol/consent, kịch bản tác vụ, danh sách người tham gia ẩn danh, dữ liệu và metric đo, thay đổi sau phản hồi.

## Minh chứng hiện có

Chưa có dữ liệu hoặc kết quả thực nghiệm người dùng. [SCRUM-85 W7 data readiness](scrum-85-w7-data-readiness.md) hoàn tất checklist và browser evidence bằng fixture; consent UI vẫn ghi retention chưa chốt. Đây không phải pilot data hay user-study result.

## Còn thiếu / cần xác minh

Chưa có thực nghiệm người dùng; fixture và dữ liệu kiểm thử do nhóm tạo không thay thế tiêu chí này. Retention policy, quyền lưu trữ ngoài Git và roster cần chốt trước khi thu người học.

Khi có evidence mới, thêm dòng gồm: Evidence ID, nguồn/path hoặc URL, ngày, owner, Prompt/Task/AC nếu áp dụng, revision/checksum và trạng thái xác minh. Chỉ ghi số liệu và trạng thái PASS khi có phép đo cùng evidence tương ứng.
